Drone System for Search and Rescue Operations

Summary

Repository

The goal was to develop a drone system to aid in search and rescue operations. However, we decided expand the project so that all members have some work to do. We ended up developing:

  • A ground station to control and monitor drones including a database
  • A communication protocol between the drone and ground station
  • An algorithm to automatically move the drone based on a set of waypoints
  • A map based waypoint software to control the automated algorithm
  • A multi-drone monitoring and control software, with multi video feed capabilities
  • A drone simulation software (In case we could not use actual drones due to covid)

    • With the project being so big I did not fully understand how all the different parts worked, but I did understand the parts I was responsible for. Specifically the simulation and the monitoring and control software. In the end, I leaner how to do OOP, how to use pygame and how to intercept and modify network packets.
