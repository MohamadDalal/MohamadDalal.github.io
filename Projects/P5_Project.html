Simulating Inter-Satellite Communication in Satellite Constellations

Summary

Repository

The goal of this project was to analyze the performance of TCP congestion algorithms in satellite cluster communication. Specifically communication in-between satellites in a satellite cluster.
For that we built a NS-3 simulation of two lines of satellites passing next to each other, and analyzed how the performance of TCP was effected.
This was my first non-python project, as we had to use C++ for NS-3. I ended up being the one sadled with coding the entire thing, so it was a good chance to get some experience with C++.
