Forest Fire Detection by Drawing Red Pixles on Overhead Forst Images and Detecting them (wow)

Repository

This was not my proudest project. The goal was to use satellite imagery to detect forest fires and aide in rescue missions. Unfortunately, due to not being able to find data, and being extremely inexperience with working with images, especially since we did not have any courses about this yet, the project ended up being reduced to drawing red pixles on satellite images and then detecting them.
Regardless, I did end up learning a lot about how satellites and satellite monitoring works.
